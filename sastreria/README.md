# Sistema de Gestión de Sastrería

Sistema web moderno para administrar pedidos de sastrería desarrollado con React + Google Apps Script + Google Sheets.

## Características

- Registro de pedidos con validación
- Cálculo automático de saldos pendientes
- Subida de fotografías a Google Drive
- Búsqueda y filtrado de pedidos
- Gestión de abonos
- Historial por cliente
- Dashboard con estadísticas
- Reportes con exportación CSV
- Diseño responsive
- Interfaz en español
- Formato moneda GTQ

## Instalación rápida

`ash
cd sastreria
npm install
cp .env.example .env
# Configurar VITE_GAS_URL en .env
npm run dev
`
